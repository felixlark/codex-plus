# 窗口编号

每个主 Codex 窗口在现有左下角 Codex Plus 圆形按钮中央显示 1、2……，点击仍打开同一个原生设置页。保持页脚位置、原生间距、点击区域、主题颜色及键盘访问；不新增入口。圆环中的 SVG 数字使用 currentColor，SVG 对辅助技术隐藏，按钮名称保持 Codex Plus，标题和辅助描述提供窗口编号。

## 接入、数据与生命周期

现有 feature-entry 接入升级到协议2，热替换旧入口，不重载聊天。controller 经自有已验身份的本机连接，查询实时主页面 target；叠加层及其他工具页面不分配编号。每个 target 保留自己的正整数编号，新窗口领取最小空闲编号，窗口移动与列表顺序变化不重排。关闭窗口后编号可复用。

映射只写入既有 launcher/state.json，不读写原生聊天、侧栏元数据或屏幕模板。恢复连接前先验证现有宿主身份，再恢复映射；Plus 重启和同 target 页面重载沿用编号。宿主关闭后新建的窗口重新分配编号。只有成功取得实时目标列表才回收已关闭编号，查询失败保留上次映射。异常旧编号恢复为唯一有效编号。退出 Plus 时沿用现有 dispose 清理，停用后保留原生 Codex 正常运行。

不改变窗口侧栏独立状态、屏幕模板、排序协议8、工具窗口定位及自动发送偏好。未来宿主入口变更沿现有源码摘要守卫报告 unsupported；编号功能可随 Plus 更新或退出移除。

## 验收

分配器检查目标乱序、保存/恢复、新建/关闭、无效重复编号；全仓检查及签名安装。正式安装版两个真实主窗口可见不同数字，原生设置动作可用；正常重启 Plus 后，同一 target 编号及各窗口布局保持。证据见验收文档及本机 window-number-20261114 日志。
