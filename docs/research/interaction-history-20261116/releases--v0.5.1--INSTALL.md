# Codex Plus 0.5.1：自动发送建议提示词

Codex 已经把下一步提示词写好了，还要你守着按 Tab、回车。这个版本补上一个开关：本轮结束后，自动采纳原生建议并发送，开始下一轮。

## 下载与安装

下载本页的 `Codex-Plus-0.5.1-macOS-arm64.zip`，解压后将 `Codex Plus.app` 拖入「应用程序」。首次安装无需自行编译。

1. 已安装旧版时，先从菜单栏正常退出 Codex Plus，再替换 App。
2. 本包有 Developer ID 签名，尚未经过 Apple 公证。macOS 首次打开可能阻止运行。请先核对本页提供的文件校验值，只在你信任本项目时，按 Apple 的说明在「系统设置 → 隐私与安全性」中为这个 App 选择「仍要打开」：https://support.apple.com/102445 。保留系统的全局安全设置。
3. 保存 Codex 当前输入，正常退出官方 Codex，再打开 Codex Plus。从 Plus 菜单栏选择「打开 Codex」，让页面增强接入。后台任务和未保存工作应先妥善处理。
4. 从 Plus 菜单栏或页面左下角 Plus 入口打开设置，在「页面增强」中打开「自动发送建议提示词」。该开关默认关闭。

可选校验命令：将 ZIP 和 `SHA256SUMS.txt` 放在同一目录，在该目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 支持范围

- Apple Silicon Mac，macOS 13 或更新版本。本页二进制为 arm64，不适用于 Intel Mac。
- 当前审核的官方 Codex 版本：26.1106.51428。本版本的启动入口要求官方宿主位于 `/Applications/ChatGPT.app`，其签名身份为官方 Codex；其他路径或版本尚未适配，请不要覆盖或修改官方包来强行匹配。
- 需要你的官方 Codex 已经能显示原生建议提示词。这个工具负责采纳与发送，不提供预测资格。OpenAI 当前将该预测功能作为个人 ChatGPT Pro 的 beta 提供，限成年人及支持的模型/聊天类型；资格以官方说明为准：https://help.openai.com/en/articles/20001601-composer-predictions-in-codex 。Codex Plus 是第三方工具，与 ChatGPT Plus 订阅无关。
- 本机真实验收覆盖英文界面、本地 Codex 聊天；远程来源及更多界面语言保留单独验收状态。

## 开启后的行为

当前前台聊天本轮结束，并且空输入框出现新的原生建议时，Plus 自动采纳并通过原生发送按钮开始下一轮。原生预测不会在每一轮都出现。

用户开始输入、切换聊天、切到其他 App、出现附件或对话框时，尚未发送的动作会取消，已采纳草稿保留。每个来源 turn 最多尝试一次；控制器恢复或结果未知时不自动重发。你可以随时关闭开关。接受并发送的新一轮按正常 Codex 用量计算，可能连续消耗用量；预测服务本身的计费以 OpenAI 说明为准。

该功能适合你已经认可原生建议方向、希望减少重复按键的工作。它处理当前前台聊天，不是无人值守的后台任务调度器。退出 Codex Plus 会停止后续自动操作，官方 Codex 继续运行。
