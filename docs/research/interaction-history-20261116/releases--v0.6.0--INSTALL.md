不用打开目标会话，Codex 也能接着做。打开“自动发送建议提示词”后，一轮结束产生新的原生建议时，Plus 会在后台发送并开始下一轮；你可以继续留在别的会话里。

## 下载与安装

下载本页的 `Codex-Plus-0.6.0-macOS-arm64.zip`，解压，将 `Codex Plus.app` 放入“应用程序”。无需自行编译。

1. 升级前保存工作，从菜单栏正常退出旧版 Codex Plus，再替换 App。升级会沿用原自动发送开关；新安装默认关闭。
2. 本包具有 Developer ID 签名，尚未经过 Apple 公证。首次打开若被 macOS 阻止，请核对校验值，只在信任本项目时按 [Apple 的说明](https://support.apple.com/102445)为该 App 选择“仍要打开”；保留系统全局安全设置。
3. 保存官方 Codex 中的草稿，妥善安排在途任务后正常退出宿主。从 Plus 菜单栏选择“打开 Codex”，由 Plus 启动并接入页面增强。官方 Codex 应用包和签名不会被修改。
4. 从菜单栏或页面左下角 Plus 入口进入设置，在“页面增强”中打开“自动发送建议提示词”。看到“已开启 · 前后台聊天的新建议将自动发送”后，保留 Codex 与 Plus 运行。无需打开目标会话或替它按发送。

可选完整性检查：把 ZIP 和本页 `SHA256SUMS.txt` 放在同一目录，然后运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 使用条件与边界

- Apple Silicon Mac，macOS 13 或更新；本包为 arm64，未提供 Intel 二进制。
- 当前适配的官方宿主为 Codex 26.1106.51428。本版本启动入口要求它位于 `/Applications/ChatGPT.app`；其他安装路径、版本尚未适配，请不要修改官方包强行匹配。
- 需要官方原生建议资格及相应设置。OpenAI 当前说明该预测功能处于个人 ChatGPT Pro 的成人 beta，支持指定模型和会话类型；以[官方资格说明](https://help.openai.com/en/articles/20001601-composer-predictions-in-codex)为准。Codex Plus 是第三方工具，与 ChatGPT Plus 订阅无关。
- 本次后台自动发送真实验收覆盖本地普通 Codex 会话、英文界面。原生过滤的会话、计划/自动化等类型、SSH/远程来源及更多界面语言不声称已覆盖。
- 仅处理开启后新产生且仍有效的原生建议，不补造建议，也不补发启动或恢复前的旧建议。原生不会在每轮都产生建议；没有建议时不会自动开下一轮。
- 目标会话有未发送草稿、附件，或状态不满足发送条件时会跳过，保留原输入；每个来源轮最多尝试一次，未知结果不重发。无需切换目标会话，沿用它原有的模型、工作区与权限。
- 自动发送会按建议直接发起任务，可能连续续轮并消耗正常 Codex 用量。仅在你认可自动采纳建议时开启；生成预测本身的 beta 计量以官方说明为准。关闭开关可停止尚未获准提交的动作，已提交请求无法由开关撤回。
- Codex 与 Plus 都需保持运行并正常连接；本版本不承诺休眠、断网或应用退出后仍能继续工作。
