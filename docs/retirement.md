# Mac 增强与 iOS 客户端的迁移记录

当前状态：迁移进行中，独立 Codex Plus 尚未退役。

Mac 界面增强、手机宿主与网关统一归入 SmartShadow 人机交互模块；iOS 客户端保持原有发布身份与界面。系统中台继续承担统一管理与生命周期职责。

保留范围包括工作区、侧栏布局、窗口编号、任务排序、建议风险审查与自动续轮、工具窗口路由，以及原有偏好、手机配对、草稿和未知尝试记录。

手机专用 Codex 宿主按限定授权使用专用 OCU 虚拟屏。人工窗口保持原位，通用 Agent 虚拟工作区不恢复。

验收顺序为：固定源码与成套签名产物、正式安装切换、Mac 增强交互、手机会话与收发/流式、断线重连和受影响重启，最后迁清调用方并退役独立应用。

目前尚未完成统一版 Mac 与 iOS 的实际验收。真实版本、运行证据和原件保留在受控交付记录中；本页在实际验收完成后更新退役结果。
