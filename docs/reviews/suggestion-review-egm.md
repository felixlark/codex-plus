# 后台建议审查评审

2026-11-14。用户批准方案后实施；主 Agent 是唯一源码及安装 writer。所有评审使用宿主原生 fresh-context 子代理，提供稳定设计或冻结候选，行为约束只读，不读取个人记忆、不操作 GUI。工具未提供实际模型 ID 或总 token，不推断多模型/成本收益。

- 初审两个独立视角：实施就绪和设计批评。发现接口/状态定义、首屏历史不足、安装采样隔离启用门槛、unknown 不应可批准、缺替代方案等 Major。主 Agent 核实并补入 `docs/designs/suggestion-review.md` 的“接口、状态和实施门槛”。
- fresh-context 定向复审实际读取设计及标准，结论无剩余 Blocker/Major；该结论不覆盖安装版真实运行。
- 独立代码审查实际读取发送桥、策略、controller、Swift UI/pipe及测试；发现一项 P1：硬敏感风险只有模型成功后才写入线程标记，审查失败后下一轮“继续”可能自动放行。
- 修复：捕获时同步粘住已识别敏感范围，早于历史加载/模型调用。新增失败后间接续跑回归。另一 fresh-context 定向复核实际源码与测试，并执行未落盘的旧候选被替代、稍后成功/失败两路径；结论该 P1 已解决，无遗留发现。

代码评审不替代 native sample 的工具隔离/源历史对账、签名安装及后台真实续轮验收；实际结果在 `docs/acceptance.md` 和本机候选证据中另列。

- 升级/窗口职责：独立复核 NnGo 是主窗口持久化职责标志，并非发送权限；Plus 独立账户/owner/生命周期核验保留。旧协议关闭租约，未知页阻断。
- 重连独立审查发现输入检查与重载间竞态、回执先于接入完成；以 trusted-input 操作失效标记、同 renderer 同步复核及实际 protocol5/registered 就绪读回修复，定向复审无剩余 P1/P2。
- 验收范围独立审查发现无效 UUID 回退日常无范围模式；以 absent/thread/invalid 三态、主程序和 launcher 双检查、RAM-only 开关修复，并覆盖空值、重复参数、等号形式。定向复审已关闭原 P1。
- controller 关闭路径独立定向复核：EOF、真实 OS 父进程存活、10秒清理上限、stopping guard；未发现剩余 P1/P2，parent liveness 定向检查通过。安装版父进程退出后 controller 9.8秒退出、宿主保留是单列运行证据。
- 启动责任归属 helper 由既有截图任务提供并归还 writer，保持 LaunchServices 启动和受认证本机端点验证。仅源码/测试纳入；本轮未冷启宿主，不宣称截图归属问题真实验收通过。
